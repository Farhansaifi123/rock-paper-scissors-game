# Stone Paper Scissors Game 🎮

A simple **Stone–Paper–Scissors** game built using **Python**.  
This is a beginner-friendly project that runs in the terminal and helps practice basic Python concepts like conditions, dictionaries, and randomization.

---

## 🕹️ How to Play
1. Run the Python file
2. Enter your choice:
   - `r` → Stone (Rock)
   - `p` → Paper
   - `s` → Scissor
3. The computer will randomly choose its move
4. The winner is decided based on the game rules

---

## 📜 Game Rules
- Stone beats Scissor
- Scissor beats Paper
- Paper beats Stone
- Same choice results in a draw

---

## 🛠️ Technologies Used
- Python
- Random module
